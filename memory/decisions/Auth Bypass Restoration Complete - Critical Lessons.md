## 🎯 CRITICAL LESSONS LEARNED

### 1. Template System Deployment is MANDATORY
**Problem**: Auth bypass template exists but wasn't deployed during regular ansible runs
**Root Cause**: Template deployment requires explicit tag `--tags auth-bypass`
**Solution**: Template system must be part of regular deployment workflow

### 2. Docker Role Force-Replaces All Files
**Discovery**: Docker compose role replaces entire directory contents
**Impact**: Live-only configurations (not in git) get wiped during deployments
**Lesson**: ALL configurations must be in git or generated via templates

### 3. Service Architecture Pattern Enforcement
**Two Systems**:
- **~30 Regular Services**: Added via Pangolin UI (auth-protected external access)
- **9 Auth Bypass Services**: Template-generated bypass routes
**Pattern Violation**: Adding regular services to static config breaks the architecture

### 4. Testing Must Include Internal Connectivity
**Discovery**: External 502 errors were actually internal connectivity issues
**Resolution**: Media VM deployment fixed the root connectivity problem
**Lesson**: Always verify internal before external when debugging service access

## 🔧 DEPLOYMENT COMMANDS THAT WORKED

```bash
# Deploy auth bypass template system
ansible-playbook deploy_vps.yml --tags auth-bypass

# Restart Traefik to load new config

# Deploy media services
ansible-playbook -i ansible/inventory.yml ansible/site.yml --limit media-vm

# Verify service status
ansible media-vm -i ansible/inventory.yml -m shell -a 'docker ps | grep -E "(sonarr|radarr|jellyseerr)"'
```
